# White-Box Principles

1. **Full reconstructability** — Every decision, spike train, weight update, and developmental step must be replayable from recorded lineage + history alone.

2. **No hidden state** — Any composition that introduces non-inspectable state fails the package screen.

3. **Lineage integrity** — Label-only reconstruction is rejected. Exact DMR → BRQ → BSA → RES → CPK chain is required.

4. **Coverage ≠ Authorization** — A complete CPK never grants authority to act.

5. **Composition screening** — Individual resource safety does not imply package safety.

6. **Observability first** — MEA-style probes and decision traces are first-class citizens, not optional instrumentation.

7. **Developmental transparency** — Maturation trajectories (plasticity, neurogenesis, evolutionary changes) are themselves inspectable objects inside CPKs.
